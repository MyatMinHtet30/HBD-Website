# Thiri's birthday surprise

A responsive, buildless birthday website with an original SVG cake, candle smoke, confetti, a Burmese birthday message, and replay controls. No install, backend, API keys, or JavaScript libraries required.

## Open locally

Open `index.html` in your browser. Keep `style.css` and `script.js` next to it. Google Fonts supplies DM Sans, Playfair Display, and Noto Sans Myanmar when online; system fonts are used otherwise.

## Publish with GitHub Pages

1. Create a GitHub repository, for example `thiri-birthday`.
2. Upload `index.html`, `style.css`, and `script.js` to its root and commit them to `main`.
3. In the repository, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select **main** and **/ (root)**, then click **Save**.
5. Once GitHub finishes deployment, open the website link shown in Pages settings, typically `https://YOUR-USERNAME.github.io/thiri-birthday/`.

## Interactions

- Open the surprise or unwrap the note to reveal the exact Burmese message.
- Tap the cake or press “Blow the Candles! 🎂” to extinguish all five flames, animate smoke, and launch confetti.
- Relight the candles to repeat the wish.
- Keyboard navigation, live announcements, and reduced-motion preferences are supported. Reduced motion disables decorative animation and confetti while preserving every interaction.
